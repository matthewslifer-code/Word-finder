# WordFinder

A simple static WordFinder website.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload these files to a GitHub repository and import that repository into Vercel.

## Before launch
- Replace YOUR-DOMAIN.com in robots.txt and sitemap.xml.
- Expand the word list substantially before applying for advertising.
- Add Privacy Policy, Terms, About, and Contact pages.
- Add analytics and test mobile/desktop behavior.
